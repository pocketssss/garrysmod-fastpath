# GLua FastPath

Библиотека для Garry's Mod: ускоряет вызов hooks и добавляет функции для `math`, `Vector` и `Color`. Подходит для часто вызываемого Lua-кода; результат зависит от сценария и состава аддонов.

## Установка

Скопируйте папку **`fastpath`** из репозитория в `garrysmod/addons/`:

```text
garrysmod/addons/fastpath/lua/
├── autorun/libs_init.lua
└── libs/
    ├── hook.lua
    ├── math.lua
    ├── vector.lua
    └── color.lua
```

Библиотеки подключаются автоматически на сервере и клиенте. Если установлена старая папка `glibus`, замените её на `fastpath`, чтобы не загружать библиотеку дважды.

## Использование

Обычный интерфейс hooks сохраняется:

```lua
hook.Add("Think", "FastPathExample", function()
    -- Ваш код
end)

hook.Remove("Think", "FastPathExample")
```

Дополнительно доступны приоритеты, pre/post hooks, приближённая тригонометрия и методы Vector. [Примеры и описание API](docs/API.md).

## Сравнение со стандартными функциями

Замеры в GMod от 8 октября 2026. Коэффициент = время стандартной функции / время FastPath: **больше 1 — быстрее, меньше 1 — медленнее**. Server и client измерены отдельно; небольшие различия чувствительны к JIT.

| Функция / сценарий | × Server | × Client |
|---|---:|---:|
| math.Clamp | 0.47 | 6.25 |
| math.max / Max2 | 0.65 | 0.64 |
| math.min / Min3 | 0.77 | 0.75 |
| math.sin / qsin | 1.78 | 1.74 |
| math.cos / qcos | 1.65 | 1.62 |
| sin+cos / sincos | 1.64 | 1.08 |
| math.random / SharedRandomFast | 0.65 | 0.66 |
| Color | 1.10 | 0.37 |
| ColorAlpha | 0.76 | 0.34 |
| HSVToColor | 0.95 | 2.73 |
| HSLToColor | 1.00 | 2.82 |
| Vector clamp (new) | 3.36 | 3.82 |
| Vector lerp (in place) | 1.16 | 1.11 |
| hook.Call 1 | 4.97 | 4.52 |
| hook.Call 10 | 1.78 | 14.99 |
| hook.Call 100 | 2.34 | 2.03 |
| hook.Add update 1 | 0.94 | 0.96 |
| hook.Add+Remove 1 | 0.17 | 0.30 |
| hook.Add update 100 | 0.77 | 0.83 |
| hook.Add+Remove 100 | 0.02 | 0.02 |

Число у hook — количество callbacks. Update заменяет существующую функцию, Add+Remove измеряет пару операций. Vector clamp/lerp сравниваются с эквивалентами через стандартный API; тригонометрия и random имеют другую точность или семантику.

### FPS и время Lua на сервере

Синтетическая нагрузка: 1000 вызовов события с 100 callbacks на каждый кадр/тик. Это результат данного теста, а не ожидаемый прирост на любом сервере.

| Показатель | Стандартные hooks | FastPath | Изменение |
|---|---:|---:|---:|
| Средний FPS | 131.34 | 194.02 | +47.7% |
| Время тестовой Lua-нагрузки, мс/тик | 4.70 | 1.98 | −57.9% |

Тест выполнен на локальном сервере с другими аддонами. Клиентское окно было без фокуса, с повышенным лимитом фонового FPS; меню закрыто. Сервер сохранил заданную частоту тиков. Измерено время тестового Lua-кода, а не загрузка процессора всего сервера.

Практический вывод: FastPath полезнее для вызова стабильных списков hooks и работы с Vector. Max2/Min3, Color и частая регистрация hooks не дают универсального выигрыша.

## На что обратить внимание

- Регистрируйте hooks при загрузке. Частые Add/Remove копируют списки callbacks и могут обходиться дороже стандартной реализации.
- Переиспользуйте постоянные Color и Vector. Методы Vector без `Get` меняют исходный объект, а методы с `Get` создают новый.
- `qsin`, `qcos` и `sincos` — приближения. Их скорость оплачивается погрешностью; `SharedRandomFast` также не является эквивалентом `math.random` или `util.SharedRandom`.
- `hook.GetTable()` возвращает снимок: изменение этой таблицы не меняет зарегистрированные hooks.

## Совместимость

Замена `hook` действует на весь Lua-код соответствующего realm. Проверяйте библиотеку со своими аддонами перед установкой на рабочий сервер. FastPath препятствует загрузке hook-модуля ULib; при обнаружении DLib предупреждает о конфликте. Нативные методы Vector, включая Length, Distance, Dot и Cross, не переопределяются.
