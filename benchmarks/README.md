# Замеры FastPath

Результаты от 8 октября 2026: [server.json](2026-10-08/server.json), [client.json](2026-10-08/client.json), [сцена](2026-10-08/scene.png). JSON содержит время каждого повтора, разброс, погрешности приближений и проверки совместимости.

## Методика

GMod 2026.09.22, x86-64, Sandbox, `gm_construct`, локальный singleplayer/listen server. Workshop отключён; другие локальные аддоны оставались включены. JIT включён в обоих realms. Это сравнение отдельных функций и синтетической нагрузки, а не A/B-тест полного игрового сервера.

Библиотеки загружены в приватное окружение: глобальный `hook` игры не заменялся. Время измерено через [SysTime](https://wiki.facepunch.com/gmod/Global.SysTime): 10 000 вызовов прогрева и 9 повторов по 100 000 вызовов. Add+Remove — 10 000 пар. Порядок сторон чередуется, перед парой выполняется полный GC. Для каждой стороны компилируется отдельный цикл; результаты Color и новых Vector сохраняются, чтобы JIT не исключил создание объектов. Время в JSON включает цикл и сохранение результата; накладные расходы не вычитаются.

- **Vector clamp:** `GetClamped` против `Vector(math.Clamp(x), math.Clamp(y), math.Clamp(z))`.
- **Vector lerp:** `LerpTo` против `Set(LerpVector(...))`; исходный вектор сбрасывается одинаково.
- **Hooks:** строковые идентификаторы, callbacks записывают аргумент в upvalue и не возвращают результат. Update заменяет существующую функцию. Add+Remove — пара операций с указанным количеством постоянных callbacks.
- **Loop control / hook.Call 0:** могут почти полностью оптимизироваться JIT; сохранены в JSON, но исключены из обзорной таблицы.

Нагрузка на кадр/тик: 1000 dispatch × 100 callbacks. Фазы idle → stock → FastPath → FastPath → stock → idle, по 2 секунды прогрева и 5 секунд записи; камера фиксирована. Средние значения взвешены по числу образцов. FPS рассчитан из среднего интервала между клиентскими Think; время Lua — только выполнение тестовой нагрузки. Окно было без фокуса; `fps_max`, `fps_max_nofocus` и `fps_max_menu` заданы как 300, vsync отключён, меню закрыто. Tick interval — 15 мс.

## Точность и совместимость

На сетке из 20 001 точки в диапазоне [−π, π] максимальная абсолютная ошибка: qsin/qcos — около 0,00109; sincos sin — 0,00449, cos — 0,01997. Это результат проверки сетки, не верхняя граница для любых входов. SharedRandomFast использует другой генератор и общее состояние.

В обоих realms прошли проверки false return с шестью значениями, fallback gamemode, 360 входов HSV/HSL, переноса hooks и повторной загрузки, а также alpha=false у Color/ColorAlpha. [Прогон до исправлений](2026-10-08-before-fixes/server.json) сохранён как воспроизведение ошибок; его FPS не используются в итогах.

Измерены исходники из Git-ревизии `5f7e7a1`. CRC записаны в JSON. После замеров папка библиотеки переименована в `fastpath`; пути диагностического скрипта обновлены. Исторические результаты не пересчитаны задним числом.

## Повторить тест

Бенчмарк рассчитан на checkout `garrysmod/addons/garrysmod-fastpath`, содержащий корневую `lua/` и вложенную `fastpath/`. Для обычного использования библиотеки устанавливается только папка `fastpath`.

1. Создать пустой файл `benchmarks/RUN_ONCE` в checkout.
2. Запустить GMod с параметрами:

   ```text
   -windowed -w 1280 -h 720 -novid -noworkshop -condebug +fps_max 300 +fps_max_nofocus 300 +fps_max_menu 300 +mat_vsync 0 +sv_lan 1 +map gm_construct
   ```

3. Не открывать меню до `COMPLETE client` в `console.log`. Сначала тестируется server, затем client. JSON сохраняются в `garrysmod/data/fastpath_bench/`.
4. Удалить `RUN_ONCE`, чтобы следующий запуск не запускал тест. На загруженной карте тест можно запустить через `lua_run include("fastpath/benchmark.lua")` в консоли локального сервера.
5. Скопировать JSON в `benchmarks/2026-10-08/` и обновить таблицу:

   ```powershell
   powershell -NoProfile -ExecutionPolicy Bypass -File benchmarks/update-readme.ps1
   ```

Для проверки сохранённого прогона: `python benchmarks/verify.py`. Проверка CRC относится к указанной исторической ревизии; для нового прогона нужно обновить ревизию проверки.
